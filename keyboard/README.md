# 镜好好键盘 · iOS16 试验1

独立的包含 App＋键盘扩展。通过 `textDocumentProxy.insertText` 输入电脑已经确认的中文、英文和表情，不使用 WDA 控件树。现有 WDA 相册组件保留。

## 使用

1. 使用 Sideloadly 自行签名安装 `MirrorGoodGood-Keyboard-iOS16-unsigned.ipa`。Apple 登录信息无需提供给镜好好或上传 GitHub。
2. 在“设置 → 通用 → 键盘 → 键盘 → 添加新键盘”启用镜好好键盘，再开启允许完全访问。
3. 在备忘录的测试输入框长按 🌐，切换到镜好好键盘。手机连接数据线并开启投屏。
4. 在修订10工作台选中这台手机，点击“连接手机键盘”，输入手机键盘上显示的 6 位码。点击投屏中的输入框后使用电脑输入法。
5. 多台手机各自安装并配对；点击哪台画面，只向哪台提交文字。旧草稿不自动重放。

组件仅监听 `127.0.0.1:9031`，通过已有 USB mux 转发，不要求手机/电脑在同一 Wi-Fi，不监听局域网。配对码和文字只留内存，不写日志或设置文件。扩展退出、切换键盘、服务重启或不确定的提交结果后需要手动重新连接。

切换输入框后需在投屏中点击一次以更新文档绑定。提交前比对 `documentIdentifier`；输入位置变化时拒绝写入。回车是用户的明确按键，目标 App 可能把它解释为发送，测试时只输入文字，不按回车。

苹果允许 App 禁止第三方键盘；密码和部分号码输入框不可用。部分外接蓝牙键盘可能隐藏软件键盘；可在“辅助触控”中启用“显示屏幕键盘”，或使用修订10的纯鼠标 BLE 配置并重新配对。USB 回环监听在真实键盘扩展内能否持续运行、签名安装、闲鱼兼容、真实电脑输入法、多机和长时间稳定性，均须实机验证。

## 构建

Windows `python build.py --prepare-only` 只生成项目，不能编译。Mac / Xcode 16.4 执行 `python3 build.py` 生成未签名 IPA。将本目录放在 GitHub 仓库 `keyboard/`，把 `.github/workflows/build-keyboard.yml` 放到仓库根目录对应位置即可云构建。发布物不包含证书、描述文件或个人资料。

## 结果含义

`proxy_invoked` 只代表 UIKit 输入接口被调用，不能据此断言第三方 App 显示了文字。电脑选词、扩展接收、手机实际显示必须分别验证。本组件没有读取输入框正文、自动重试、自动粘贴、全局输入或任意控件回退。
